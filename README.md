# Six City Police Department

Website tra cứu thông tin, quy tắc roleplay và bộ luật của Six City Police Department (SCPD).

## Yêu cầu

- Node.js 20 trở lên
- npm

## Chạy cục bộ

```bash
npm install
npm run dev
```

Mở `http://localhost:3000` trong trình duyệt.

## Kiểm tra

```bash
npm run lint
npm run typecheck
npm run build
```
